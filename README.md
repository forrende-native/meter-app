# จดมิเตอร์ (Meter Reading PWA)

เว็บแอปจดค่ามิเตอร์ไฟ/น้ำ หลายตึก/หลายห้อง ใช้งานผ่านมือถือได้ทุกที่ (HTTPS ถาวร) และยังใช้ออฟไลน์ได้ 100% หลังติดตั้งครั้งแรก
ข้อมูลเก็บในเครื่อง (localStorage) เป็นหลัก ไม่มีฐานข้อมูลกลาง, export เป็น Excel/CSV ได้, สำรองขึ้น Google Drive ได้,
และซิงก์ขึ้น Google Sheet อัตโนมัติเพื่อให้ระบบจัดการหอพักหลัก (dorm) ดึงไปใช้คิดบิลต่อได้โดยไม่ต้องพิมพ์ซ้ำ

**ใช้งานจริงที่**: https://forrende-native.github.io/meter-app/

**ดูภาพรวมการทำงานแบบง่าย (diagram)**: เปิดไฟล์ `diagrams/simple-meter-dorm.html` ในเครื่อง (อธิบาย 3 ขั้นตอน
"จดมือถือ → เก็บที่ PMNmeter (Google Sheet) → ระบบ Dorm กดปุ่มดึงไปใช้" เข้าใจง่ายแม้ไม่ใช่สายเทคนิค)
หรือ `diagrams/meter-sheet-dorm-sync.html` สำหรับเวอร์ชันละเอียดกว่า

## ฟีเจอร์

- เพิ่มมิเตอร์/ห้องได้หลายจุด แยกตึก + แยกประเภทไฟ/น้ำ (ล็อกไม่ให้ลบจากหน้าจอ กันลบผิดพลาดหน้างาน มีตัวกันเพิ่มมิเตอร์ซ้ำด้วย)
- นำเข้ารายชื่อห้องจากฐานข้อมูลหอพักจริงได้อัตโนมัติตอนเปิดแอปครั้งแรก (seed data, กันซ้ำด้วย)
- เลือก "ตึก" ก่อนแล้วค่อยเลือกห้อง — สะดวกเวลาจดทีละตึก ไม่ต้องไล่หาในลิสต์รวม
- บันทึกค่ามิเตอร์ใหม่ — โชว์ค่าครั้งก่อนให้อัตโนมัติ คำนวณ "หน่วยที่ใช้" ให้ดูก่อนกดบันทึก (ไม่โชว์ค่าใช้จ่ายเป็นบาทบนหน้าจอ เก็บไว้คำนวณเบื้องหลังสำหรับ export เท่านั้น)
- ดูประวัติย้อนหลัง กรองตามห้อง/มิเตอร์ ลบรายการที่กรอกผิดได้
- Export ข้อมูลเป็นไฟล์ Excel (.xlsx) หรือ CSV ได้จากปุ่มในแอป พร้อมเลือกกรองเฉพาะเดือนได้ — ทำงานออฟไลน์ได้
- สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON ในเครื่อง (กันเผื่อย้ายเครื่อง/ล้างแอป)
- เชื่อมต่อ Google Drive (OAuth) เพื่อสำรองไฟล์ JSON ขึ้นโฟลเดอร์ Drive ที่กำหนดไว้ได้โดยตรง
- **ซิงก์ขึ้น Google Sheet อัตโนมัติทุกครั้งที่บันทึก** (ผ่าน outbox queue รอส่งถ้าออฟไลน์ ไม่เสียความสามารถออฟไลน์) ให้ระบบ dorm ดึงไปใช้ต่อได้
- ติดตั้งเป็นแอปบนหน้าจอโฮมมือถือได้ (PWA) ใช้งานออฟไลน์ได้เต็มรูปแบบผ่าน Service Worker

เพราะมีชื่อตึก/เลขห้องจริง ไม่ควรเปิดเผยใน public repo

## ข้อมูลอยู่ที่ไหน

- ข้อมูลที่กรอกทั้งหมด (มิเตอร์, ค่าที่จด, ประวัติ) เก็บใน **localStorage ของเบราว์เซอร์/อุปกรณ์เครื่องนั้น** (คีย์ `meterapp_db_v1`) เป็นหลัก
- **ไม่ sync ข้ามเครื่องอัตโนมัติ** — เปิดจากมือถือเครื่องอื่น/เบราว์เซอร์อื่นจะไม่เห็นข้อมูลเดียวกัน
- ทุกครั้งที่กดบันทึกค่ามิเตอร์ ข้อมูลจะถูกส่งขึ้น **Google Sheet ชื่อ "PMNmeter - Readings Sync"** (อยู่ในโฟลเดอร์ Drive ชื่อ **"PMNmeter"**) โดยอัตโนมัติ เป็นสำเนา/สะพานเชื่อมไปยังระบบ dorm — ไม่ใช่แหล่งข้อมูลหลัก (ถ้าออฟไลน์ตอนบันทึก ข้อมูลจะเข้าคิวรอส่งทีหลังเมื่อมีเน็ต)
- ถ้าต้องการสำรองข้อมูลออกนอกเครื่องแบบเต็ม มี 2 ทาง: (1) Export เป็น JSON/Excel/CSV ด้วยมือ หรือ (2) เชื่อมต่อ Google Drive แล้วกดสำรองขึ้น Drive ได้โดยตรง (ดูหัวข้อ Google Drive ด้านล่าง)
- ล้างข้อมูลเบราว์เซอร์ (Clear browsing data) หรือถอนแอปที่ติดตั้งไว้ จะลบข้อมูลในเครื่องนั้นทันที (ข้อมูลที่เคย sync ขึ้น Google Sheet แล้วยังอยู่ แต่ประวัติ/การตั้งค่าในเครื่องกู้คืนไม่ได้ถ้าไม่มีไฟล์สำรอง)

## วิธีใช้งาน (ฝั่งแอปมือถือ "จดมิเตอร์")

1. เปิด https://forrende-native.github.io/meter-app/ บนมือถือหรือคอมพิวเตอร์ (ที่ไหนก็ได้ ไม่ต้องอยู่ใน LAN เดียวกับใคร)
2. (แนะนำ) กดเมนูเบราว์เซอร์ → "Add to Home screen" / "ติดตั้งแอป" เพื่อใช้เป็น PWA ใช้งานออฟไลน์ได้เต็มรูปแบบหลังจากนั้น
3. แท็บ **"มิเตอร์/ห้อง"** — ถ้ายังไม่มีมิเตอร์เลย แอปจะนำเข้าชุดห้อง/ตึกเริ่มต้นให้อัตโนมัติ (จาก `seed_meters.js`, กันซ้ำในตัว) / เพิ่มมิเตอร์เองทีละรายการก็ได้ (ลบจากหน้าจอไม่ได้โดยเจตนา)
4. แท็บ **"บันทึก"** — เลือกตึก → เลือกห้อง → ใส่วันที่ → กรอกเลขมิเตอร์ปัจจุบัน ระบบคำนวณหน่วยที่ใช้ให้ดูก่อน กดบันทึก (ข้อมูลจะถูกซิงก์ขึ้น Google Sheet อัตโนมัติด้วย)
5. แท็บ **"ประวัติ"** — ดูรายการย้อนหลังทั้งหมด กรองตามห้องได้ ลบรายการที่กรอกผิดได้
6. แท็บ **"Export"** — เลือกเดือนที่ต้องการ (หรือทั้งหมด) แล้วกด "Export Excel"/"Export CSV" เพื่อดาวน์โหลดไฟล์ลงเครื่อง (คอลัมน์: ตึก, ห้อง/มิเตอร์, ประเภท, วันที่, เลขครั้งก่อน, เลขครั้งนี้, หน่วยที่ใช้, อัตรา, ค่าใช้จ่าย, หมายเหตุ)

## วิธีใช้งาน (ฝั่งระบบ dorm — ดึงข้อมูลมาคิดบิล)

ระบบ dorm เป็นคนละโปรเจกต์ (`D:\OneDrive - Rende Development Co., Ltd\0.b\dorm`, รันที่ `http://localhost:3000`)
ไม่ได้แชร์โค้ดกับ meter-app เลย เชื่อมกันผ่าน Google Sheet เท่านั้น:

1. เปิด http://localhost:3000 แล้ว login เป็น admin
2. ไปที่แท็บ **"ตั้งค่าระบบ"** → เลื่อนหาการ์ด **"นำเข้าค่ามิเตอร์จาก Google Sheet"**
3. กดปุ่ม **"นำเข้าจาก Google Sheet"** — ระบบจะดึงข้อมูลจาก Sheet "PMNmeter - Readings Sync" มาจับคู่น้ำ+ไฟของห้อง/วันเดียวกัน แล้วเติมเข้าตารางมิเตอร์ของ dorm อัตโนมัติ (ข้ามรายการซ้ำ, พักรายการที่ยังไม่ครบคู่น้ำ-ไฟไว้ก่อน)
4. ดูผลลัพธ์ได้ทันทีที่แท็บ **"มิเตอร์น้ำไฟ"** (ตารางจดมิเตอร์ปกติ) หรือแท็บ **"รายงานมิเตอร์"** (ดูประวัติย้อนหลังรายห้องพร้อมจำนวนเงินที่ต้องชำระ แยกน้ำ/ไฟ ตามช่วงเดือนที่เลือก)
5. ข้อมูลที่นำเข้าแล้วจะถูกใช้คิดบิลในแท็บ "ใบแจ้งหนี้" ตามปกติ — การนำเข้าเป็นแบบกดเองทุกครั้ง ไม่ใช่ sync อัตโนมัติต่อเนื่อง

## สำรองข้อมูลขึ้น Google Drive

ในแท็บ Export มีส่วน "สำรองขึ้น Google Drive":

1. กด **"🔗 เชื่อมต่อ Google Drive"** — ครั้งแรกจะเด้งหน้า Google ให้ login + ยืนยันสิทธิ์ (ต้องเป็นบัญชีที่ถูกเพิ่มเป็น Test user ใน Google Cloud OAuth consent screen)
2. หลังเชื่อมสำเร็จ กด **"☁️ สำรองขึ้น Drive ตอนนี้"** — ไฟล์ JSON ของข้อมูลทั้งหมดจะอัปโหลดตรงเข้าโฟลเดอร์ Drive ที่กำหนดไว้ล่วงหน้าในโค้ด (`drive.js` → `DRIVE_FOLDER_ID`)
3. Token การเชื่อมต่อถูกเก็บไว้ใน localStorage ชั่วคราว (หมดอายุแล้วต้องกดเชื่อมต่อใหม่)

ขอบเขตสิทธิ์ที่ขอ (OAuth scope) คือ `drive.file` — แอปเข้าถึงได้เฉพาะไฟล์ที่แอปสร้างขึ้นเองเท่านั้น ไม่เห็น/แก้ไฟล์อื่นใน Drive ของคุณ

ตั้งค่าที่เกี่ยวข้อง (แก้ได้ที่ต้นไฟล์ `drive.js`):
- `GOOGLE_CLIENT_ID` — OAuth Client ID จาก Google Cloud Console (ชนิด Web application, ตั้ง Authorized JavaScript origins เป็น `https://forrende-native.github.io`)
- `DRIVE_FOLDER_ID` — ID ของโฟลเดอร์ Drive ปลายทาง (เอามาจากท้าย URL ของโฟลเดอร์)

> หมายเหตุ: แอปยังอยู่สถานะ "Testing" ใน Google Cloud (ยังไม่ผ่าน verification) — login ได้เฉพาะอีเมลที่เพิ่มเป็น Test user ไว้เท่านั้น และตอน login อาจเจอหน้าเตือน "Google hasn't verified this app" ให้กด Advanced → Go to (unsafe) เพื่อดำเนินการต่อได้ตามปกติ (ปลอดภัยเพราะเป็นแอปที่สร้างเอง)

## Deploy / แก้ไขโค้ด

โค้ดอยู่ที่ GitHub repo `forrende-native/meter-app` branch `master`, deploy ผ่าน GitHub Pages (serve ตรงจาก root ของ branch)

แก้ไฟล์แล้ว deploy ใหม่:
```bash
cd "D:/HermesWorkspace/meter-app"
git add -A
git commit -m "อธิบายการแก้ไข"
git push
```
GitHub Pages จะ build ใหม่อัตโนมัติภายใน ~1 นาที หลัง push

**ข้อควรระวัง**: ห้าม commit ไฟล์ที่มีข้อมูลห้อง/ตึกจริงจากฐานข้อมูลหอพัก (`rooms_export.json`, `meters_import.json`) หรือไฟล์ credential ใดๆ (เช่น `client_secret_*.json` จาก Google Cloud Console) ขึ้น repo นี้เพราะเป็น public repo — ทั้งหมดอยู่ใน `.gitignore` แล้ว ตรวจสอบก่อน push ทุกครั้งถ้าเพิ่มไฟล์ใหม่

Bump `CACHE_NAME` ใน `sw.js` ทุกครั้งที่แก้ไฟล์ที่ cache ไว้ (index.html, app.js, drive.js, style.css, ฯลฯ) ไม่งั้น Service Worker จะยังเสิร์ฟไฟล์เก่าจาก cache ให้ผู้ใช้ที่เคยเปิดแอปนี้มาก่อน

## หมายเหตุทางเทคนิค

- ไม่มี backend/database ของตัวเอง — ทุกอย่างรันบนฝั่ง client (HTML/CSS/JS ล้วน), Google Drive เป็นทางเลือกสำรองข้อมูลเสริม ไม่ใช่ที่เก็บข้อมูลหลัก
- สร้างขึ้นใหม่ทั้งหมด ไม่ใช่ fork จาก [MrTG1B/MeterReadingApp](https://github.com/MrTG1B/MeterReadingApp) (ซึ่งเป็น Flask backend + ต้องมีเซิร์ฟเวอร์รันตลอดเวลา) — ออกแบบให้ทำงานแบบ client-only + ติดตั้งเป็น PWA แทน
