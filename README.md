# จดมิเตอร์ (Meter Reading PWA)

เว็บแอปจดค่ามิเตอร์ไฟ/น้ำ หลายห้อง/หลายจุด ใช้งานบนมือถือแบบออฟไลน์ได้ 100%
ข้อมูลเก็บในเครื่อง (localStorage) ไม่ต้องมีเซิร์ฟเวอร์ฐานข้อมูล, export เป็น Excel/CSV ได้เมื่อจะเอาไปใช้ต่อ

## ฟีเจอร์

- เพิ่มมิเตอร์/ห้องได้หลายจุด แยกประเภทไฟ/น้ำ ตั้งอัตราค่าบริการต่อหน่วยแยกแต่ละจุด
- บันทึกค่ามิเตอร์ใหม่ — โชว์ค่าครั้งก่อนให้อัตโนมัติ คำนวณหน่วยที่ใช้ + ค่าใช้จ่ายให้ดูก่อนกดบันทึก
- ดูประวัติย้อนหลัง กรองตามห้อง/มิเตอร์ ลบรายการที่กรอกผิดได้
- Export ข้อมูลทั้งหมด (ทุกมิเตอร์/ห้อง) เป็นไฟล์ Excel (.xlsx) หรือ CSV ได้จากปุ่มในแอป — ทำงานออฟไลน์ ไม่ต้องพึ่งเน็ต
- สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON (กันเผื่อย้ายเครื่อง/ล้างแอป/เปลี่ยนมือถือ)
- ติดตั้งเป็นแอปบนหน้าจอโฮมมือถือได้ (PWA) ใช้งานออฟไลน์ได้เต็มรูปแบบผ่าน Service Worker

## โครงสร้างไฟล์

```
meter-app/
├── index.html          หน้าตาแอป (4 แท็บ: บันทึก / มิเตอร์-ห้อง / ประวัติ / Export)
├── style.css            สไตล์
├── app.js               ลอจิกทั้งหมด (จัดการข้อมูล, คำนวณ, export, service worker)
├── manifest.json         ข้อมูล PWA (ชื่อ ไอคอน สี) สำหรับ "Add to Home screen"
├── sw.js                 Service Worker — cache ไฟล์ทั้งหมดไว้ใช้ออฟไลน์
├── xlsx.full.min.js      ไลบรารี SheetJS สำหรับสร้างไฟล์ .xlsx (ฝังไว้ในเครื่อง ไม่โหลดจากเน็ต)
├── gen_icons.py          สคริปต์สร้างไอคอนแอป (รันครั้งเดียวตอน setup แล้ว)
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

ข้อมูลที่กรอกทั้งหมดเก็บอยู่ใน localStorage ของเบราว์เซอร์บนมือถือเครื่องนั้น (คีย์ `meterapp_db_v1`)
ไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลออกนอกเครื่อง

## วิธีใช้งาน (ติดตั้งครั้งแรก)

### 1. รันเซิร์ฟเวอร์ชั่วคราวบน PC (เพื่อติดตั้งแอปลงมือถือ)

เปิด terminal ที่โฟลเดอร์นี้ แล้วรัน:

```
python -m http.server 8899
```

### 2. หา IP ของเครื่อง PC ในวง LAN

```
ipconfig
```

ดูที่ "IPv4 Address" เช่น `192.168.1.50`

### 3. เปิดบนมือถือ

- มือถือต้องต่อ WiFi วงเดียวกับ PC
- เปิด Chrome บนมือถือ ไปที่ `http://<IP เครื่อง PC>:8899/index.html`
  เช่น `http://192.168.1.50:8899/index.html`

### 4. ติดตั้งเป็นแอป (Add to Home screen)

- กดเมนู 3 จุดมุมขวาบนของ Chrome → "Add to Home screen" / "ติดตั้งแอป"
- จากนั้นเปิดจากไอคอนบนหน้าจอโฮมได้เลย **โดยไม่ต้องเปิดเซิร์ฟเวอร์บน PC อีก** — ใช้งานออฟไลน์ได้เต็มรูปแบบ (Service Worker cache ทุกไฟล์ไว้ในเครื่องมือถือแล้ว)

> ปิดเซิร์ฟเวอร์บน PC ได้หลังจากติดตั้งเสร็จ ไม่กระทบการใช้งานต่อไป
> ถ้าในอนาคตอยากแก้โค้ดแอป (เช่น เปลี่ยนสี, เพิ่มฟีเจอร์) ต้องรันเซิร์ฟเวอร์ใหม่แล้วเปิดหน้าเดิมอีกครั้งให้ Service Worker ดึงไฟล์ใหม่ไปอัปเดต

## วิธีใช้งานประจำวัน

1. แท็บ **"มิเตอร์/ห้อง"** — เพิ่มห้อง/จุดวัดที่ต้องจด พร้อมตั้งอัตราค่าไฟ/น้ำต่อหน่วย (ทำครั้งเดียวตอนเริ่มต้น เพิ่มเติมได้ภายหลัง)
2. แท็บ **"บันทึก"** — เลือกห้อง ใส่วันที่ กรอกเลขมิเตอร์ปัจจุบัน ระบบคำนวณหน่วยที่ใช้และค่าใช้จ่ายให้ดูก่อน กดบันทึก
3. แท็บ **"ประวัติ"** — ดูรายการย้อนหลังทั้งหมด กรองตามห้องได้ ลบรายการที่กรอกผิดได้
4. แท็บ **"Export"** — เมื่อจะเอาข้อมูลไปใช้ต่อ (ทำบิล, ส่งเจ้าของหอ ฯลฯ) กด "Export Excel" หรือ "Export CSV" ไฟล์จะดาวน์โหลดลงเครื่องมือถือทันที (ไปที่โฟลเดอร์ Downloads ของมือถือ) มีคอลัมน์: ห้อง/มิเตอร์, ประเภท, วันที่, เลขครั้งก่อน, เลขครั้งนี้, หน่วยที่ใช้, อัตรา, ค่าใช้จ่าย, หมายเหตุ

## สำรองข้อมูล

แนะนำกด **"สำรองข้อมูล (JSON)"** เป็นระยะ (เช่น ทุกเดือน) เผื่อย้ายเครื่อง ล้างแคชเบราว์เซอร์ หรือเปลี่ยนมือถือ
กู้คืนได้ที่ปุ่ม **"กู้คืนจากไฟล์ JSON"** ในแท็บเดียวกัน (จะเขียนทับข้อมูลปัจจุบันทั้งหมด)

**ข้อควรระวัง**: ข้อมูลผูกกับเบราว์เซอร์ + อุปกรณ์เครื่องนั้น การล้างข้อมูลเบราว์เซอร์ (Clear browsing data) หรือถอนแอปจะลบข้อมูลด้วย ควรสำรองไฟล์ JSON ไว้เสมอ

## หมายเหตุทางเทคนิค

- ไม่มี backend/database — ทุกอย่างรันบนฝั่ง client (HTML/CSS/JS ล้วน)
- ปรับแต่งได้โดยแก้ไฟล์ `app.js`, `style.css`, `index.html` ตรงๆ แล้วรันเซิร์ฟเวอร์ใหม่เปิดหน้าเว็บอีกครั้งให้ Service Worker อัปเดต cache
- สร้างขึ้นใหม่ทั้งหมด ไม่ใช่ fork จาก [MrTG1B/MeterReadingApp](https://github.com/MrTG1B/MeterReadingApp) (ซึ่งเป็น Flask backend + ต้องมีเซิร์ฟเวอร์รันตลอดเวลา) — ออกแบบให้ทำงานออฟไลน์แบบ client-only ล้วนแทน
